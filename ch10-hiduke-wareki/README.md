## 実行のしかた

リポジトリのルートを作業ディレクトリにして実行してください（RStudio の Session → Set Working Directory → Choose Directory...）。

```r
source("ch10-hiduke-wareki/chapter10.R")
```

1行ずつ試したいときは、[`chapter10.R`](./chapter10.R) を開いて上から順に実行してください。
