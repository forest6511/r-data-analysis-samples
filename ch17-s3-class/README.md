# 第17章　S3クラスとジェネリック関数

『Rによるデータ分析 入門から実践』の第17章のサンプルコードです。

## 章の構成

- **17.1** 同じ関数が違う表示をする
- **17.2** `class()` と `typeof()` は別のもの
- **17.3** クラスは複数持てる
- **17.4** メソッドが無ければ `default` が使われる
- **17.5** クラスの付け替えは値の意味を変える
- **17.6** どのメソッドが呼ばれるかを調べる
- **17.7** 分析の結果もクラスを持つ
- **17.8** 自分のデータに表示を与える
- **17.9** `summary()` や演算子も定義できる
- **17.10** S3 以外の仕組み
- **17.11** クラスを知ると説明が付くこと
- **17.12** まとめ

## 実行のしかた

リポジトリのルートを作業ディレクトリにして実行してください（RStudio の Session → Set Working Directory → Choose Directory...）。

```r
source("ch17-s3-class/chapter17.R")
```
