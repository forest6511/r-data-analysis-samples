# 第12章　データ構造の正体

『Rによるデータ分析 入門から実践』の第12章のサンプルコードです。

## 章の構成

- **12.1** `R` にはスカラーがない
- **12.2** 型は6つ、`class()` とは別のもの
- **12.3** 型は自動で1つに寄せられる
- **12.4** 長さが違うベクトルは繰り返される
- **12.5** リストは違う型を入れられる
- **12.6** `[` と `[[` は別のものを返す
- **12.7** データフレームはリストである
- **12.8** `data.frame` と `tibble` は挙動が違う
- **12.9** 値を書き換えても元は変わらない
- **12.10** 因子は整数と選択肢でできている
- **12.11** 行列とデータフレームは別のもの
- **12.12** 空のベクトルで繰り返しが1回多く回る
- **12.13** データフレームはリストを列にできる
- **12.14** 実務での使い分け
- **12.15** まとめ

## 実行のしかた

リポジトリのルートを作業ディレクトリにして実行してください（RStudio の Session → Set Working Directory → Choose Directory...）。

