# 第13章　ネイティブパイプ |>

『Rによるデータ分析 入門から実践』の第13章のサンプルコードです。

## 章の構成

- **13.1** パイプは入れ子を左から右に開くもの
- **13.2** `|>` は文法、`%>%` はパッケージの関数
- **13.3** 実行速度は約8倍違う
- **13.4** `%>%` は第1引数以外にも渡せる（`.`）
- **13.5** `|>` の位置指定は `_`（名前付き引数のみ）
- **13.6** `_` は `$` の前にも置ける（R 4.3.0 以降）
- **13.7** 右側は必ず関数呼び出しの形にする
- **13.8** `substitute()` の結果が変わる（実務で最もつまずく差）
- **13.9** 演算子の優先順位に注意する
- **13.10** `%>%` で書かれたコードを読む
- **13.11** どちらを使うか
- **13.12** パイプを使わないほうがよい場合
- **13.13** まとめ

