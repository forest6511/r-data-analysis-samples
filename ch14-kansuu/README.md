# 第14章　関数を書く

『Rによるデータ分析 入門から実践』の第14章のサンプルコードです。

## 章の構成

- **14.1** 書き写しが何を起こすか
- **14.2** 関数にまとめる
- **14.3** 戻り値は最後の式
- **14.4** 戻り値は1つだけ。複数返すならリスト
- **14.5** 既定値を付ける
- **14.6** 引数は名前で指定できる
- **14.7** 引数を検査する
- **14.8** 選択肢を限定する `match.arg()`
- **14.9** 可変長引数 `...`
- **14.10** 関数の中と外は別の場所
- **14.11** `dplyr` の列名を引数で受け取る
- **14.12** 後片付けを予約する `on.exit()`
- **14.13** 関数を書く順序
- **14.14** まとめ

## 実行のしかた

リポジトリのルートを作業ディレクトリにして実行してください（RStudio の Session → Set Working Directory → Choose Directory...）。

```r
source("ch14-kansuu/chapter14.R")
```

1行ずつ試したいときは、[`chapter14.R`](./chapter14.R) を開いて上から順に実行してください。
