# 第16章　エラーを設計する tryCatch

『Rによるデータ分析 入門から実践』の第16章のサンプルコードです。

## 章の構成

- **16.1** `R` が異常を伝える3つの方法
- **16.2** `message()` は標準エラー出力に出る
- **16.3** `tryCatch()` でエラーを捕まえる
- **16.4** `tryCatch(warning = )` は処理を中断する
- **16.5** 中断せずに記録する `withCallingHandlers()`
- **16.6** `finally` で後片付けを予約する
- **16.7** `try()` は古い書き方
- **16.8** 自分の関数からエラーを出す
- **16.9** クラスを付けて、対処を分岐できるようにする
- **16.10** 複数ファイルの処理に組み込む
- **16.11** どこまで捕まえるか
- **16.12** まとめ

## 実行のしかた

リポジトリのルートを作業ディレクトリにして実行してください（RStudio の Session → Set Working Directory → Choose Directory...）。

```r
source("ch16-trycatch/chapter16.R")
```

1行ずつ試したいときは、[`chapter16.R`](./chapter16.R) を開いて上から順に実行してください。
