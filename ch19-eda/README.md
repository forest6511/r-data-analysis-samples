# 第19章　探索的データ分析（EDA）

『Rによるデータ分析 入門から実践』の第19章のサンプルコードです。

## この章で使うデータ

- [`uriage_2y.csv`](../uriage_2y.csv)

## 章の構成

- **19.1** まず形を見る
- **19.2** `glimpse()` は列が多いときに使う
- **19.3** `summary()` で列ごとの分布を見る
- **19.4** 欠損がどこにあるかを見る
- **19.5** 最大値の正体を確かめる
- **19.6** 統計的な外れ値と、誤りは別のもの
- **19.7** ありえない値を探す
- **19.8** カテゴリの列は件数を数える
- **19.9** 集計する前に、まだ集計しない
- **19.10** 1件の誤りが相関を作り替える
- **19.11** 分布を図で見る
- **19.12** EDA の手順をまとめる
- **19.13** EDA で答えを出そうとしない
- **19.14** まとめ

## 実行のしかた

リポジトリのルートを作業ディレクトリにして実行してください（RStudio の Session → Set Working Directory → Choose Directory...）。

```r
source("ch19-eda/chapter19.R")
```

1行ずつ試したいときは、[`chapter19.R`](./chapter19.R) を開いて上から順に実行してください。
