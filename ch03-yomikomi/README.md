## 実行のしかた

リポジトリのルートを作業ディレクトリにして実行してください（RStudio の Session → Set Working Directory → Choose Directory...）。

```r
source("ch03-yomikomi/chapter03.R")
```

1行ずつ試したいときは、[`chapter03.R`](./chapter03.R) を開いて上から順に実行してください。
