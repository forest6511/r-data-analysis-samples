# 第11章　欠損値NAの伝播と型変換の事故

『Rによるデータ分析 入門から実践』の第11章のサンプルコードです。

## この章で使うデータ

- [`uriage.csv`](../uriage.csv)

## 章の構成

- **11.1** 列の型が数値になっていない
- **11.2** `-` を欠損として読む
- **11.3** `NA` は計算の結果まで伝わる
- **11.4** `na.rm = TRUE` は分母を変える
- **11.5** 0 で埋めるか、除くか
- **11.6** `filter()` は欠損の行を残さない
- **11.7** `case_when()` は欠損を既定値に入れる
- **11.8** `group_by()` は欠損を1つの群にする
- **11.9** 型変換で値が変わる
- **11.10** 整数の桁あふれと小数の誤差
- **11.11** `NA` の仲間を見分ける
- **11.12** 実務での使い分け
- **11.13** まとめ

## 実行のしかた

